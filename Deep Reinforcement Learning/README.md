# RL Toolbox サンプル: グリッドワールドでのQ学習

Reinforcement Learning Toolbox を使った最小構成のサンプルです。5×5のグリッドワールド上で、テーブル型Q学習エージェントがスタート地点からゴールまで、障害物を避けて移動する方策を学習します。

## ファイル

- `rl_gridworld_demo.m` — 環境構築・エージェント学習・可視化を行う単体スクリプト

## 必要環境

- MATLAB R2025b（動作確認済み）
- Reinforcement Learning Toolbox

## 実行方法

MATLAB のカレントフォルダをこのディレクトリに設定し、以下を実行します。

```matlab
rl_gridworld_demo
```

## やっていること

1. **環境構築**（`createGridWorld` + `rlMDPEnv`）
   - 5×5のグリッド、スタート `[2,1]`、ゴール（終端状態）`[5,5]`、障害物 `[3,3]`
   - 各ステップの報酬は -1、ゴール到達時のみ +10
   - `ResetFcn` で毎エピソードの開始位置を `[2,1]` に固定
2. **エージェント構築**（`rlTable` + `rlQValueFunction` + `rlQAgent`）
   - テーブル型Q値関数を用いたQ学習エージェント
   - ε-greedy探索（初期ε=0.3、減衰率0.01）、割引率0.9
3. **学習**（`train`）
   - 最大200エピソード、移動平均報酬が8に達するか200エピソードで停止
   - `Plots="training-progress"` によりRL Toolbox純正の学習進捗ウィンドウをライブ表示
4. **可視化**
   - 学習曲線（エピソード報酬・移動平均報酬）を独立したFigureとして再描画
   - `plot(env)` を学習済みエージェントのシミュレーション前に呼ぶことで、グリッド上をエージェントが移動する様子をライブアニメーション表示
   - 学習後の経路をグリッド上に線とステップ番号で描画した静止画サマリーを作成
5. **シミュレーション**（`sim`）と学習した経路のコンソール出力

## 実行結果の例

```text
--- Training complete ---
Episodes run: 200
Final average reward: 3.90

--- Learned path from [2,1] to [5,5] ---
[2,1] -> [3,1] -> [3,2] -> [4,2] -> [5,2] -> [5,3] -> [5,4] -> [5,5]
```

実行すると以下の4つのウィンドウが開きます。

- RL Toolbox純正の「Training Progress」アプリ（学習中のライブグラフ）
- `Training Progress`（学習曲線を再描画した保存用Figure）
- グリッドワールドのライブアニメーション（無題のFigure）
- `Learned Path Summary`（学習後の経路をまとめた静止画）

## 補足・詰まりやすい点

- `env.ResetFcn` は**引数なし**で初期状態のインデックス（数値）を返す関数を渡す必要があります。`GW.States` の中から該当する状態文字列のインデックスを `find` で取得して使っています。
- `sim` の戻り値 `experience` に含まれる観測データのフィールド名は `Observation.MDPObservations`（`timeseries` オブジェクト）です。
- 乱数シードは `rng(0)` で固定していますが、学習結果（学習曲線・最終方策）は環境やMATLABバージョンにより多少変動する場合があります。

## アレンジ例

- グリッドサイズ・障害物・報酬設計を変更して難易度を調整
- `rlQAgent` を `rlSARSAAgent` に差し替えてオンポリシー学習と比較
- 状態空間を連続値にして `rlDQNAgent`（ニューラルネットワークベースの価値関数）に拡張
